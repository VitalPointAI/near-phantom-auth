<objective>
Implement enterprise binding persistence in the Postgres adapter while preserving the default schema. This plan gives later service/session/SCIM work a durable third-track storage layer.
</objective>

<threat_model>
T-18-01 default anonymity regression: enterprise tables must not be initialized for default installs. Mitigate by keeping DDL in `POSTGRES_ENTERPRISE_SCHEMA` and requiring an explicit `initializeEnterprise()` call.

T-18-05 duplicate provisioning: concurrent IdP retries must not create duplicate enterprise identities. Mitigate with `UNIQUE (external_idp, external_sub)` and idempotent service behavior in later plans.
</threat_model>
