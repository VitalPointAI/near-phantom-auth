<objective>
Implement the opt-in `auth.enterprise` binding API on top of the enterprise persistence adapter. This plan creates the server-side mechanism that SCIM and future OIDC/SAML connectors will call.
</objective>

<threat_model>
T-18-05 duplicate provisioning: repeated `linkIdentity` calls for the same external subject must return the existing binding without minting another MPC account.

T-18-02 PII and secret leakage: enterprise event payloads may include stable identifiers, but must never include bearer tokens, raw request bodies, cookies, passkey material, or error messages.
</threat_model>
