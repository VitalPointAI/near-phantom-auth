<objective>
Add session track discrimination and enterprise status enforcement. This plan turns deprovisioning from a row update into an access-control guarantee.
</objective>

<threat_model>
T-18-03 offboarding only advisory: a deprovisioned enterprise user must lose access even if they already have a cookie. Mitigate by deleting sessions during status changes and checking active status in middleware/requireAuth.

T-18-02 cross-track PII leakage: enterprise request attachment must be separate from `req.anonUser`.
</threat_model>
